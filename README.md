### How I build

- **从真实问题出发** — 关注使用场景，让工具解决具体问题。
- **重视完整体验** — 从界面与交互，到交付与持续迭代。
- **分享有用的实践** — 把组件、脚本和工作流沉淀成可复用的东西。
